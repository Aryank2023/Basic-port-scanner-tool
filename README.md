# 🔍 Python Port Scanner

A simple and lightweight port scanner built using Python.  
This tool checks whether specific ports on a target host are open or closed.

---

## 🚀 Features

- Scan multiple ports
- Fast connection check using socket
- Timeout handling
- Clean and simple output

---

## 🛠️ Technologies Used

- Python 3
- Socket Library
